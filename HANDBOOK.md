# HANDBOOK — big-o-ladder

Developer guide. README.md is for students; this is for whoever edits the code.

## What it is
A single static HTML page (no framework, no build dependencies) that teaches Big O: a ladder of complexity classes, an SVG chart, a searchable catalog, and code-pattern cards. Hosted on GitHub Pages from `main`.

## Files
| Path | Role |
|---|---|
| `src/page.html` | **Single source.** An HTML fragment: `<title>`, `<style>`, markup, `<script>`. No doctype/head/body, because the same fragment is also published as a Claude Artifact, which wraps it in its own skeleton. |
| `index.html` | Generated by `scripts/build.py`: the fragment wrapped in a standalone skeleton for GitHub Pages. Never hand-edit. |
| `scripts/build.py` | The 12-line wrapper. Run after every change to `src/page.html`. |
| `README.md` | Student-facing usage. |
| `CODEX.md` | Abbreviations used in the code. |
| `IDEAS.md` | Append-only idea log. |

## Architecture (all inside `src/page.html`)
- **Tokens.** Every color is a CSS custom property on `:root`; dark values are redefined under `@media (prefers-color-scheme: dark)` guarded by `:root:not([data-theme="light"])` and again under `:root[data-theme="dark"]`. Series colors are `--c0`..`--c6` (fastest to slowest) and chip fills `--chip-0`..`--chip-6`. The seven hues are the dataviz reference categorical palette in its fixed CVD-safe order; do not reorder them.
- **`CLS`** defines the seven classes in ladder order with `f(n)` (actual value) and `lg(n)` (log10 of the value, computed directly so n! and 2ⁿ never overflow). Everything else derives from this array.
- **`clsOf(str)`** maps a complexity string from the tables (`"n log n"`, `"V + E"`, `"n²"`, `"1*"`) to a class id. Add new spellings there if a table cell shows a grey chip.
- **Catalog arrays** `DS`, `ALG`, `JAVA`, `PAT`, `OPS`, `CONCEPTS` are plain rows (see README for the shapes). `ENTRIES` flattens them into the search index with `kind`, `name`, `alias`, `main` (the headline complexity) and `ops`. `OPS` rows carry `ops.on` (the structure) and `boost: 10` so "pop" ranks the operation above the Stack card. `CONCEPTS` have no class (`main: ""`), so the answer card shows the term and definition without a chip.
- **Search** scores name and aliases (exact 100, prefix 80, substring 60, token hits, note match 20) plus the boost, shows the top 10, and `show(e)` renders the answer card. All text goes in through `textContent`.
- **Ladder** renders one button per class with a sparkline of `lg(n)` for n = 1..24 and the operation count at the current slider n. Clicking sets `filter`, which re-renders the catalog and the filter pills.
- **Chart** is hand-drawn SVG (960×420 viewBox, responsive). `draw()` samples 161 points, builds paths, places end labels and spreads overlapping ones 13px apart. Log mode plots `lg(n)`; linear mode clips at 20× the quadratic value and marks clipped labels with ↑. The crosshair tooltip lists every visible series at the snapped n. `on[]` holds the legend toggles; 2ⁿ and n! start off.
- **Wall-time table** uses `timeStr(log10 ops, rate)` so factorial values stay representable.

## Run / build / test
- Run: open `index.html`, or `python -m http.server 8000`.
- Build: `python scripts/build.py` after editing `src/page.html`.
- Test: there is no test suite. Smoke check in a browser: search "hash map", click a rung, drag the slider to 1,000,000, toggle linear, toggle O(n!) on, resize to phone width, flip the OS to dark. Open the console; there should be no errors.

## Deploy
Push to `main`. GitHub Pages serves `index.html` from the root of `main` within a minute or two at https://roketteere.github.io/big-o-ladder/. Work on `dev`, merge to `main` when it is checked.

## Working with Claude on this
Point Claude at `src/page.html` and the data arrays. Ask for a row, not a rewrite. After a change, Claude should run `scripts/build.py`, open the page once, and commit with a one-line subject. Commits are authored by Joel only, no co-author trailers.
